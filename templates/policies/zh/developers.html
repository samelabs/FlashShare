518.PLUS 上的工具是一个由你托管的 HTTPS 端点：平台将用户的调用转发至端点，并把端点返回的结果交付给用户。一次发布，网页与 MCP（Model Context Protocol）两个消费面同时生效，共用同一条调用管线与同一套结算。本页是端点需要实现的完整契约。

发布流程

  1. 实现一个符合本页契约的 HTTPS 端点。文末提供两个可运行的最小实现。
  2. 在发布表单提交工具声明。每个账号最多 {{ max_tools }} 个工具；工具标识（tool_id）为 2–41 个字符，以小写字母开头，只能包含小写字母、数字与下划线。新工具默认不公开。
  3. 在工具页面完成一次成功运行。
  4. 在「我的工具」中将工具公开。公开后进入市场，并可通过 MCP 的 catalog_search 被检索。

开始发布

请求格式

平台以 JSON 正文向你的端点发起 POST：

POST https://your-endpoint.example/your-path
Content-Type: application/json

{
  "files": [
    { "filename": "photo.png", "content_type": "image/png", "size": 123456,
      "url": "{{ base_url }}/api/source/FILE-ID?t=ONE-TIME-TOKEN" }
  ],
  "params": { "mode": "fast" }
}
  • files：调用方提供的输入文件。文件内容不随请求传输；每个文件以一次性签名 URL 交付，同时附带文件名、类型与大小，由端点在处理请求期间自行下载（或按需忽略）。签名 URL 仅可使用一次，且很快失效。
  • params：仅包含你在声明中定义的参数及其取值。
  • 端点须在 {{ timeout_min_s }}–{{ timeout_max_s }} 秒内应答，具体时限在发布表单中设定。

返回格式

端点以 JSON 返回一个 items 数组，按顺序列出结果项：

{
  "items": [
    { "kind": "text", "text": "Done — result at {{ base_url }}/f/abc123" },
    { "kind": "json", "data": { "width": 64, "height": 32 } },
    { "kind": "file", "filename": "out.png", "content_type": "image/png",
      "data_b64": "iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAADUlEQVR42mNk+M9QDwADhgGAWjR9awAAAABJRU5ErkJggg==" }
  ]
}

三种结果项：

  • text——字符串，原样存储与展示。其中的 URL 自动转为链接；当结果仅含一个 https 链接时，结果卡以该链接为主呈现。
  • json——任意 JSON 值，网页以格式化形式展示，MCP 端作为结构化内容返回。
  • file——文件项，通过 data_b64（base64 编码的字节）或 url（由平台服务端拉取并存储）交付，落档后获得下载页与直链，图片类文件在结果页直接显示。

约束：

  • 每次调用最多 {{ max_items }} 项。
  • text 与 json 项合计不超过 {{ inline_max_bytes }} 字节。
  • 文件单件不超过 {{ max_upload_mb }} MB，输入与输出同限。
  • 每项的 kind 须属于发布时声明的输出类型集合。
  • 输出文件的分享参数（有效期与下载次数）由调用方在调用时选择。

端点返回非 2xx 状态，或响应不符合上述格式时，本次调用判定失败，调用方获得全额退款。

参数声明

最多 {{ max_params }} 个参数，类型为 enum（固定选项）、number（可选上下界）、boolean、text 四种。text 参数取值上限 {{ text_param_chars }} 字符。必填参数由平台先行校验，通过后才调用端点。

文件声明

接受格式以扩展名列表声明（.png、.pdf…），数量窗口为 0 到 {{ files_max }} 个。纯文本工具（文件上限为 0）不声明格式，其第一个 text 参数即为输入框。不符合声明的文件在调用端点之前即被拒绝。

限额汇总

  • 端点应答时限：{{ timeout_min_s }}–{{ timeout_max_s }} 秒。
  • 结果项数：每次调用最多 {{ max_items }} 项。
  • text 与 json 合计载荷：每次调用最多 {{ inline_max_bytes }} 字节。
  • 单文件体积（输入与输出）：最大 {{ max_upload_mb }} MB。
  • text 参数取值：最多 {{ text_param_chars }} 字符。

安全

  • 端点必须是公网 HTTPS 地址：私网、回环与云元数据地址一律拒绝，重定向的每一跳同样校验。
  • 输入文件的签名 URL 一次性且短时效，不可重放。
  • 可选鉴权头：提交时保存头名称与令牌（例如 Authorization: Bearer …），平台加密存储令牌并在每次调用时发送该头；传输层保留的头名（Host、Content-Length 等）不可使用。
  • 端点返回的文件在存储前经过格式白名单的字节校验，不匹配即失败。

计费与收益

每次调用的价格由你按积分设定，范围为 0（免费）到 {{ max_price }}，1000 积分 = 1 美元。每笔成功付费调用，价格扣除 {{ commission_rate if commission_rate is not none else '—' }}% 平台佣金后计入你的收益池；收益可按美元提现，最低 {{ min_withdrawal_usd }} 美元。你消费的积分与你的收益分属两个独立账户。

MCP 检索与调用

网页端每个工具拥有独立页面。MCP 端工具名为 owner__tool（例如 alice__pdf2svg）；Agent 通过 catalog_search 检索并按名调用，检索结果自带完整 input schema。用户可将工具加入收藏：收藏工具出现在其 list_favorites 列表中，并在 tools/list 里带有收藏标记。

参考实现

示例一（Python，FastAPI）：文本输入，返回 text 与 json 项。配套声明：一个名为 text 的可选 text 参数，文件上限 0。

from fastapi import FastAPI, Request

app = FastAPI()

@app.post("/shout")
async def shout(req: Request):
    body = await req.json()
    text = str(body["params"].get("text", ""))
    return {"items": [
        {"kind": "text", "text": text.upper()},
        {"kind": "json", "data": {"length": len(text)}},
    ]}

示例二（Node，零依赖）：下载签名 URL 中的文件并原样返回。配套声明：接受 .png 文件（0–1 个），无参数。

const http = require("http"), https = require("https");
http.createServer((req, res) => {
  let body = "";
  req.on("data", (c) => (body += c));
  req.on("end", () => {
    https.get(JSON.parse(body).files[0].url, (f) => {
      const chunks = [];
      f.on("data", (c) => chunks.push(c));
      f.on("end", () => {
        res.setHeader("Content-Type", "application/json");
        res.end(JSON.stringify({ items: [{
          kind: "file", filename: "copy.png",
          content_type: "image/png",
          data_b64: Buffer.concat(chunks).toString("base64"),
        }] }));
      });
    });
  });
}).listen(3000);
