本政策以平实的语言说明 518.PLUS 存储了哪些关于你的信息以及为什么。范围以运行中的代码实际处理的内容为准。

1. 本地账号

使用本地账号时，我们存储你的用户名、邮箱地址、密码哈希（密码本身不存储），以及你提供或运行服务所需的账号与个人资料字段（如语言偏好、账号状态）。

2. X OAuth

使用 X 登录时，我们存储用于账号绑定和展示的 X 账号标识及公开资料字段：X 用户 id、用户名、显示名称和头像 URL。我们不会读取你的时间线、私信或关注列表，也不会代表你发布内容。

3. 会话与 Cookie

登录会创建服务端会话，并在你的浏览器中设置会话 Cookie。该 Cookie 用于保持登录状态；会话会过期并被例行清理。

4. API Token

用于 MCP 认证的 API Token（fsk_ 前缀）仅以哈希加元数据（名称、前缀、状态、创建与最近使用时间）的形式存储。完整 Token 值仅在创建时向你展示一次；不以可读形式存储，无法找回。若遗失，请创建新 Token。

5. 上传与工具处理

上传与工具处理记录会保存文件名、大小、内容类型、下载链接、过期时间、上传时间和基础访问来源，用于额度控制、计量结算、审计和故障排查。

6. 工具调用、计量与账本

每次计量工具调用都被记录为工具调用事实，并产生账本条目：扣费、失败退款、提供者收益与平台佣金。这些记账记录用于结算、对账与争议处理。

7. 会员、订单与支付

会员状态、订单与支付记录（计划或充值包、金额、币种、支付服务商交易号、状态）会被保存，用于管理你的订阅与积分购买，并用于对账。

8. 提供者收益与提现

如果你发布工具，你的收益与提现请求记录在账本和提现登记中（金额、你提供的提现渠道、审核与处理状态），用于结算与付款。

9. 第三方工具

当你运行第三方 HTTP 工具时，你的源文件会被传递给该工具的开发者：平台向该端点提供每个文件的有时效签名下载 URL，以及文件名、内容类型、大小和你的工具参数。开发者端点在平台之外下载并处理这些文件。平台不控制该端点。请自行判断哪些文件适合交给第三方工具。

10. 文件存储边界

上传的文件存储在平台自营的专用文件存储服务（Gokapi）中。平台数据库保存映射、可见性与生命周期记录；存储服务保存文件本体。有效期与下载限制通过这些记录执行。

11. 支付服务商边界

支付与订阅由我们的支付服务商（Creem）处理。支付时你填写的账单信息由服务商按其自身条款处理；平台接收并保存订单与对账所需的交易号、金额和状态。

12. 运行、安全与审计

我们保留运行日志与记录，用于安全、反滥用、审计、对账与故障排查，包括对账号、工具与内容执行的操作记录。页面发送的浏览器端错误报告用于发现和修复故障。

13. 保留：不同的生命周期

文件与分享有自己的生命周期：按你选择的有效期与下载限制到期并删除。经济记录（扣费、收益、提现）、安全与审计记录处于另一条更长的生命周期，因为结算、反滥用与审计职责的存续期超过任何单个文件。删除文件不会抹除这些记账与安全记录。

14. 你的权利与联系

根据你所在地的法律，你可能享有查阅、更正或删除个人信息等权利。在删除数据会破坏记账或安全职责的情况下，我们可能保留这些职责所需的最少记录。行使权利或咨询本政策，请联系 ad@live.it。 支付与订阅由 Creem 处理，价格与退款规则见 /pricing。

15. 政策更新与生效日期

本政策可能随服务演进而更新；页面顶部的生效日期对应当前版本，更新将在本页面发布。
