1. 服务性质

518.PLUS 是一个 MCP 原生（MCP-native）的工具平台。工具一经发布，即可通过两个等价的使用面调用：Web 界面，供人类直接使用；MCP（Model Context Protocol）端点，供代理与自动化程序等机器调用。两个使用面运行同一条工具调用链路和同一套记账。

2. 账号

你可以使用本地账号（用户名与密码）注册，也可以使用 X（OAuth）登录。你需对账号下的所有活动负责，包括妥善保管凭据、确保所提供信息真实准确。

3. API Token

平台允许你创建用于 MCP 调用认证的 API Token（前缀为 fsk_）。完整 Token 值仅在创建时向你展示一次。你有责任妥善保管自己的 Token，并对使用该 Token 进行的全部活动负责。若 Token 泄露，请在账号页将其吊销；不要公开分享 Token 或将其嵌入共享代码。

4. 文件、处理与临时分享

你可以上传文件、使用工具处理并将结果以临时链接分享。每个分享在创建时由你选择有效期与下载次数限制；到期或达到下载上限后链接即失效，文件将由例行清理机制删除。你需自行确保上传与处理的内容合法、拥有相应权利，且不包含恶意代码。

5. 工具：第一方与第三方

工具由平台提供（第一方工具），或由其他开发者提供（第三方工具）。第三方工具运行在由其开发者控制的 HTTP 端点上。使用第三方工具即表示你理解：其处理逻辑、可用性与输出由开发者定义和控制，而非平台。付费工具的费用在使用前明确展示。

6. 第三方 HTTP 工具可能获得的内容

为完成你的请求，第三方 HTTP 工具可能获得完成任务所必需的内容：每个源文件的一个有时效的签名下载 URL，以及文件名、内容类型、大小和你提供的工具参数。该工具的开发者从这些 URL 下载文件并返回输出。请勿将你不愿暴露给该开发者的文件交给第三方工具处理。

计量工具的使用以积分支付。积分通过购买或会员计划获得——现行方案、充值包与价格见 /pricing；会员还可能改变用量配额，如上传额度、有效期档位与下载次数档位。付费工具按使用前展示的单价按次计量。失败调用按平台记账规则结算；账本是这些资金流动的记录。
