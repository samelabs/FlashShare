接入契约（HTTP API）

请求（518 → 你的端点）

POST https://your-endpoint/your-path
Content-Type: application/json

{
  "source_urls": ["{{ BASE_URL }}/api/source/...（一次性签名URL，5分钟有效）"],
  "params": { ...工具参数 }
}

你的服务按 URL 拉取源文件（平台不推文件）。超时按提交时配置（5–300s）。

响应（二选一）

A. 直接返回文件字节:  Content-Type: image/png 等（扩展名须在白名单）
B. 返回 JSON:  { "output_url": "https://you/x.png" }  （平台回拉，同样过安全校验）

鉴权（可选）

提交时配置 Header 名与令牌（如 Authorization: Bearer …），平台每次调用携带。

安全要求

端点必须 https + 公网 IP（SSRF 校验：禁私网/环回/元数据地址）。产出内容经嗅探白名单校验，不合格即拒。
