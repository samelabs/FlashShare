# 518.PLUS 标志规范

本目录是 518.PLUS 标志的唯一来源，仓库内不存在其他副本。站点通过 `/brand/` 路径直接引用本目录文件。
全部源文件为 SVG 填充路径（圆角是显式圆弧，无描边成形、无内嵌位图、无字体依赖）。

## 目录

| 路径 | 内容 |
|---|---|
| `svg/` | 标志源文件（图形标、字标、横版组合） |
| `platform/` | 平台图标与分享图的矢量源（尺寸、留白已按平台要求排好） |
| `web/` | 由 `platform/` 和 `svg/` 导出的位图，站点直接引用（favicon、PWA 图标、分享图） |

## 图形标

两张错位的卡片，表示文件的处理与分享。

### 构造（32 × 32 网格）

| 参数 | 值 |
|---|---|
| 卡片核心 | 平行四边形：宽 10，竖边 11，顶边与底边按 1:3 上斜（每横向 3 升 1，约 18.4°） |
| 卡片圆角 | 核心各边外扩 2，顶点处以半径 2 的圆弧连接；可见尺寸 14 × 18.3 |
| 前后关系 | 前卡 = 后卡 + (7, 4) |
| 整体 | 两卡可见外框 21 × 22.3，几何中心落在 (16, 16) |
| 母版底板 | 32 × 32 铺满画布，无圆角 |
| 使用版底板 | 32 × 32，圆角 rx 7（约 22%） |

### 母版与使用版

- **母版** `svg/518-mark.svg`：底板铺满画布、不带圆角。只交给自己加蒙版的平台：iOS（apple-touch-icon）、Android maskable 图标。系统会裁出圆角，母版再带圆角就成了双重圆角。
- **使用版** `svg/518-mark-rounded.svg`：同一母版，底板 rx 7。网站顶栏、favicon、PWA `any` 图标、横版组合、文档与演示中一律用这一版。不要在使用版外再套 CSS 圆角。

### 其他变体

| 文件 | 用途 | 说明 |
|---|---|---|
| `svg/518-mark-16.svg` | 仅 favicon 16px | 16 网格、像素对齐，卡片去掉圆角，底板 rx 3.5 |
| `svg/518-mark-line.svg` | 单色场景（印刷、水印、品牌色底） | `currentColor`；后卡在前卡周围让出 1.6 间隙 |

## 字标

- `svg/518-wordmark.svg`：「518.PLUS」，`currentColor`，点为品牌红。
- 字形取自 Outfit Bold（SIL Open Font License 1.1），已转为路径；本仓库不包含、也不需要该字体文件。
- 字高：大写高 706/1000 em 缩放到 40 单位；平头字形上下贴 0 / 40，圆形字形保留原字体的上下外溢。
- 定位：每个字形墨迹左缘对齐整数网格；墨迹间距统一 5 单位（字高的 1/8），L–U 收 2。
- 字标只用交付的路径，不用字体实时排版。需要纯文本时写作「518.PLUS」，不缩写、不拆开。

## 横版组合

| 文件 | 用途 |
|---|---|
| `svg/518-lockup.svg` | 浅色底：网站顶栏、文档页眉 |
| `svg/518-lockup-on-dark.svg` | 深色底（站点目前无暗色主题，仅供站外使用） |

- 图形标用使用版；字标字高 = 图形标高 × 0.45（32 高时为 14.5），垂直居中。
- 图形标与字标间距 9（32 高时），组合宽 127.355 × 32。
- 网站顶栏：高 28（宽约 111）；≤ 640px 时高 24。

## 尺寸与留白

- 四周留白不小于图形标宽度的 1/4。
- 图形标最小 20px；16px 只用于 favicon，且只用 `518-mark-16.svg`。

## 颜色

| 用途 | 值 |
|---|---|
| 底板、字标的点 | `#FF4D4D`（即 `--brand`） |
| 后卡 | `#FFC9C9` |
| 前卡 | `#FFFFFF` |
| 字标（浅色底） | `#0B0D10`（即 `--ink`） |
| 深色底的底板与点 | `#FF5C5C` |

全部为实色，不用透明度。`--brand-strong`、`--brand-600` 等交互色不用于标志。

## 平台图标

| 输出（`web/`） | 尺寸 | 矢量源 | 规则 |
|---|---|---|---|
| `favicon.ico` | 16 / 32 / 48 | `518-mark-16.svg`（16）、`518-mark-rounded.svg`（32、48） | PNG-in-ICO |
| `apple-touch-icon.png` | 180 | `platform/apple-touch-icon.svg` | 铺满，卡片宽占 62%；iOS 自加圆角 |
| `icon-192.png`、`icon-512.png` | 192、512 | `platform/icon.svg` | 使用版圆角（rx 112/512）；PWA `any` 不会被裁切 |
| `icon-192-maskable.png`、`icon-512-maskable.png` | 192、512 | `platform/icon-maskable.svg` | 铺满，卡片宽占 52%，落在 80% 安全区内 |
| `og-image.png` | 1200 × 630 | `platform/og-image.svg` | 红底、卡片、白色字标 |

修改标志时先改本目录的 SVG，再把位图导出到 `web/` 覆盖同名文件。导出时按 SVG 矢量直接渲染到目标尺寸，不从大图缩放。

## 禁止

- 不加渐变、阴影、描边；不改斜率、比例、颜色。
- 不把后卡做成半透明叠加。
- 图形标不脱离底板单独着色；单色场景只用 line 版。
- 自带蒙版的平台只用母版，其余位置只用使用版。
