# FlashShare — 项目愿景

> **快分享。** 把"分享"这件事做到极致。

## 我们在做什么

FlashShare 是一个轻量级的自托管文件分享服务。不追求大而全，只做一件事：**让分享变得简单、快速、可靠**。

上传一个文件，拿到一个链接——就这么简单。没有繁琐的注册流程，没有臃肿的客户端，没有广告。

## 核心理念

### ⚡ 快

- 零依赖，纯 Python 标准库
- 上传即分享，无需等待
- 二维码一键生成，跨设备传递
- 轻量服务，1G 内存的机器也能跑

### 🔒 可控

- 自托管，数据在自己的服务器上
- 链接可设过期时间和下载次数
- 用户自主管理文件生命周期

### 🌍 无界

- 7 种语言原生支持（en/zh/ja/ko/es/ar/de）
- 移动优先设计
- PWA 离线可用

## 演进方向

FlashShare 围绕"分享"迭代。不是做一个网盘，不是做一个协作平台，而是**把分享做透**。

### 第一阶段：基础分享（当前）
- ✅ 文件上传 + 临时链接
- ✅ 过期时间 / 下载次数控制
- ✅ 二维码生成
- ✅ 用户账号（本地注册 + X OAuth）
- ✅ 上传配额管理
- ✅ 多语言界面

### 第二阶段：分享增强
- 文本分享（粘贴即分享，类似 pastebin）
- 图片分享（压缩、预览、相册链接）
- 短链服务（自定义短码）
- 分享统计（查看次数、下载地域）
- 批量分享（多文件一条链接）
- 分享密码保护

### 第三阶段：分享生态
- 开放 API（第三方接入）
- 插件系统（自定义分享流程）
- 更多存储后端（S3、R2、本地）
- 团队空间（共享配额）
- Webhook 通知

## 设计原则

1. **零依赖优先** — 能用标准库解决的不引入第三方包
2. **小而美** — 功能聚焦，代码精简，部署简单
3. **安全默认** — CSRF 防护、文件类型校验、配额限制开箱即用
4. **开源友好** — 干净的代码结构，完善的文档，一键部署脚本

## 技术选型

| 选择 | 原因 |
|------|------|
| Python 标准库 | 零依赖，部署简单，适合小服务器 |
| SQLite | 无需额外服务，够用 |
| Gokapi | 轻量文件后端，API 简洁 |
| 纯原生 HTML/CSS/JS | 不需要构建工具，不依赖前端框架 |

## 这只是开始

FlashShare 刚刚起步。第一版做的是最基本的文件分享——上传、链接、下载。

但分享这件事可以做得更深、更广、更好。每一步迭代，都围绕同一个问题：

**怎样让分享更顺畅？**
