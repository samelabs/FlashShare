# FlashShare Roadmap

围绕"分享"，逐步做透。

---

## ✅ v1.0 — 基础分享（当前版本）

把文件分享的基本流程跑通。

- [x] 文件上传 + 临时下载链接
- [x] 过期时间 / 下载次数限制
- [x] 二维码自动生成
- [x] 用户系统（本地注册/登录 + X OAuth）
- [x] X 账号绑定/解绑
- [x] 上传配额（每日次数 + 流量限制）
- [x] 多语言界面（7 种）
- [x] PWA 支持
- [x] 一键部署脚本（setup.sh）

---

## 🚧 v1.1 — 体验打磨

不急加功能，先把基础体验做到位。

- [ ] 个人设置页完善（头像上传、修改密码）
- [ ] 文件管理优化（排序、搜索、批量删除）
- [ ] 分享链接页 UI 优化
- [ ] 移动端上传体验改进
- [ ] 错误提示国际化完善
- [ ] 分享链接自定义别名

---

## 🔮 v2.0 — 分享增强

围绕"分享"拓宽能力边界。

### 内容类型
- [ ] 文本分享（Paste / pastebin 模式）
- [ ] 短链服务（URL 缩短）
- [ ] Markdown 渲染分享
- [ ] 代码片段分享（语法高亮）

### 链接能力
- [ ] 密码保护
- [ ] 自定义过期策略（阅后即焚）
- [ ] 批量打包分享（多文件一条链接）
- [ ] 预览模式（无需下载直接查看）

### 数据洞察
- [ ] 分享访问统计（浏览次数、下载次数）
- [ ] 简单的数据面板

---

## 🌐 v3.0 — 分享生态

让 FlashShare 成为可扩展的分享平台。

- [ ] 开放 REST API
- [ ] 插件机制
- [ ] 多存储后端（S3 / R2 / Backblaze）
- [ ] 团队 / 组织空间
- [ ] Webhook + 通知集成
- [ ] CLI 工具（命令行直接分享）

---

## 原则

每个版本都要：
- 能独立部署运行
- 不破坏旧数据
- 保持零依赖（或最小依赖）
- 让"分享"更顺畅

---

*路线图会随实际需求调整，方向不变：把分享做透。*
